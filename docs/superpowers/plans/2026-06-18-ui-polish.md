# Plan: UI Polish & Icon Upgrade

## Goal
Elevate the app's UI by replacing text placeholders/emojis with proper `@expo/vector-icons/MaterialIcons`, styling the Settings header properly, and improving scroll fluidity across all lists.

## Steps

### Step 1: Replace Text & Emojis with Icons
- **`src/components/layout-toggle.tsx`**:
  - Replace `☰` / `▦` with `MaterialIcons` (`view-list` / `grid-view`).
- **`src/components/sort-button.tsx`**:
  - Replace `↑` / `↓` with `arrow-upward` / `arrow-downward`.
- **`src/app/index.tsx` (Home Screen)**:
  - Replace `<Link href="/settings">Settings</Link>` with a `<MaterialIcons name="settings" ... />` inside the Link.
- **`src/app/player.tsx`**:
  - Replace placeholder text/symbols in the top chrome with icons:
    - Back button: `<MaterialIcons name="arrow-back" ... />`
    - Rotation: `<MaterialIcons name="screen-rotation" ... />`
    - Tracks (`+`): `<MaterialIcons name="subtitles" ... />` or `audiotrack`.
- **`src/components/player/lock-overlay.tsx`**:
  - Replace `🔒` with `<MaterialIcons name={locked ? "lock" : "lock-open"} ... />`.

### Step 2: Settings Header Polish
- **`src/app/settings.tsx`**:
  - Update `<Stack.Screen>` options to match the theme.
  - Set `headerStyle: { backgroundColor: colors.background }` (or surface), `headerTintColor: colors.onSurface`, and `headerShadowVisible: false`.

### Step 3: Scroll Fluidity
- Add `bounces={true}` and `overScrollMode="always"` to:
  - `FlashList` in `src/app/index.tsx`.
  - `ScrollView` in `src/app/settings.tsx`.
  - `FlashList` in `src/app/group.tsx`.
- Verify `contentContainerStyle` has generous `paddingBottom` (`spacing.xl` or safe area) for all lists.

## Testing
- Ensure the app builds without errors (`npm run tsc`).
- Verify all icons display correctly and the Settings header is dark (in dark mode).
- Verify lists have overscroll enabled.
