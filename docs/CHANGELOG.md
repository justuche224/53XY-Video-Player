> Append-only, newest first. One bullet per shipped feature. The most recent entries live in [HANDOFF.md §7](./HANDOFF.md#7-changelog); older ones are archived here. The status table in [HANDOFF.md §2](./HANDOFF.md#2-status-table--single-source-of-truth) is the canonical feature list.

- **Moments Phase 1 — Capture & store** — a bookmark button in the player's top bar (beside the tracks button) captures the exact on-screen frame: the player's cached position (never `player.currentTime`, which throws after expo-video releases the shared object), a cleaned-up title/episode label reusing the grouping engine's `normalizeTitle`/`formatEpisodeLabel`, and a note seeded from whatever subtitle line is on screen. Rows live in a new `moments` table (migration v11) with **no foreign key to `videos`** — deliberately, since `deleteVideosByIds` runs on every scan that finds a file gone and a moment has to outlive its file, so it stores its own snapshot (title, episode label, filename, folder, video uri, duration) instead of joining live. Frames + a `moments.json` manifest are written to `/storage/emulated/0/53XY/Moments` behind a `.nomedia` (survives uninstall and Clear Data, invisible to the gallery), falling back to the app document directory when shared storage isn't writable. Required a native change: `FrameGrabber.grabFrame` gained an `exact?: boolean` option using `MediaMetadataRetriever.OPTION_CLOSEST` instead of `OPTION_CLOSEST_SYNC` — the old keyframe-snapping path can land on a completely different shot at a typical 5–10s GOP, which is fine for a poster thumbnail and wrong for a moment the user asked to save. Capture shows a confirmation snackbar with an **Edit** action opening a note sheet. **Not shipped in this phase:** no Moments browse screen, no way to view or play back a saved moment, no restore-from-manifest flow — those are Phases 2 and 3. Code-reviewed, **not yet device-verified** — this touches native Kotlin and needs a `npx expo run:android` rebuild; checklist at the end of the plan. Spec/plan: [moments-design](./superpowers/specs/2026-09-08-moments-design.md), [moments-plan](./superpowers/plans/2026-09-08-moments-capture.md).
